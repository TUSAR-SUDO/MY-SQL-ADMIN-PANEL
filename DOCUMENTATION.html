1. System Architecture & Core Stack

The GameCenter Admin Panel is an enterprise-grade full-stack management hub engineered to power multiple external browser games, mobile apps, and educational quiz platforms from a single centralized dashboard.

⚡

Single-Service Monorepo

Both the React (Vite) UI and the Express backend run inside a single Docker container on port 5000. Eliminates CORS issues, separate billing, and complex cross-domain routing.

🐬

Relational MySQL + Prisma

Strict schema validation with auto-increment IDs, cascade deletions on project removal, relational indexes, and sub-millisecond random quiz sampling.

🔐

Multi-Tier Security

JWT authentication, bcrypt password hashing, role-based access control (Super Admin / Sub Admin), and strict origin whitelisting for client game endpoints.

🤖

Generative AI Engine

Built-in integration with Google Gemini AI for instant structured quiz generation, automatic MCQ option distractor formulation, and educational hints.

3. Client Game Integration & Public API

External games (e.g. Vercel, Netlify, Unity, HTML5) fetch randomized question sessions from your public endpoint:

// Public Session Endpoint
GET /api/public/projects/:slug/session

// Query Parameters:
// ?difficulty=easy | medium | hard   (Filter by difficulty)
// ?category=ipl                      (Filter by category / tag)
// ?limit=10                          (Number of questions to serve)

React Hook Example (`useQuiz.js`)

import { useState, useEffect } from 'react';

export function useQuiz(slug = 'cricket', difficulty = 'medium') {
  const [questions, setQuestions] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch(`https://my-sql-admin-panel.onrender.com/api/public/projects/${slug}/session?difficulty=${difficulty}`)
      .then((res) => res.json())
      .then((data) => {
        setQuestions(data.questions.map((q) => ({
          question: q.field1,
          options: [q.optionA, q.optionB, q.optionC, q.optionD],
          correctAnswer: q.correctAnswer, // "A" | "B" | "C" | "D"
          hint: q.hint,
          difficulty: q.difficulty,
          category: q.category
        })));
        setLoading(false);
      });
  }, [slug, difficulty]);

  return { questions, loading };
}
